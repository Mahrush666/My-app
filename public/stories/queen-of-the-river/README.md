# The queen of the river

Teaching material supplied by the teacher in U7 Free time Lesson 5.pptx, Power up Starter, Unit 7.

- story.png is the illustrated story page extracted unchanged from ppt/media/image23.png.
- story.mp3 is the original recording extracted unchanged from ppt/media/media1.mp3 (about 3 minutes 28 seconds).

The app displays close-up views of the original page. The recording plays continuously while pictures are changed manually; scene timing is not inferred.

Mobile playback uses story-mobile.webp (same dimensions, compressed) and story-mobile.m4a (AAC, mono, 64 kbps). The original source files remain unchanged. Audio is requested on playback rather than during the initial picture load.
